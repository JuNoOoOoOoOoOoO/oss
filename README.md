## 1. top - 실시간 시스템 모니터링

`top`은 리눅스 시스템의 현재 상태를 실시간으로 보여주는 대시보드와 같다. CPU 사용량, 메모리 점유율, 실행 중인 프로세스 목록을 갱신하며 보여준다.

### 기본 사용법
```bash
top
```
### 주요 정보 (Header)
* **Load Average:** 시스템 부하 (1분, 5분, 15분 평균)
* **Tasks:** 전체, 실행 중, 슬립, 좀비 프로세스 수
* **%Cpu(s):** 사용자(us), 시스템(sy), 유휴(id) CPU 사용률
* **KiB Mem/Swap:** 메모리 및 스왑 사용량

### `top` 실행 중 사용 가능한 단축키
| 단축키 | 설명 |
| :---: | :--- |
| `q` | top 종료 |
| `k` | 프로세스 종료 (PID 입력 필요) |
| `M` | 메모리 사용량 순으로 정렬 |
| `P` | CPU 사용량 순으로 정렬 |
| `1` | CPU 코어별 사용량 보기/숨기기 |

## 2. ps - 현재 프로세스 상태 확인

`ps` (Process Status)는 명령어가 실행된 **순간**의 프로세스 스냅샷을 출력한다.

### 자주 사용하는 옵션 조합

#### 1. System V 스타일
모든 프로세스를 풀 포맷으로 출력한다.
```bash
ps -ef
```
* `-e`: 모든 프로세스 출력
* `-f`: 풀 포맷(Full format)으로 출력 (UID, PID, PPID, C, STIME, TTY, TIME, CMD)

#### 2. BSD 스타일
CPU와 메모리 점유율 등을 포함하여 보여준.
```bash
ps aux
```
* a: 다른 사용자의 프로세스도 표시
* u: 사용자 중심의 포맷으로 출력 (USER, PID, %CPU, %MEM...)
* x: 터미널 제어 없이 실행되는 프로세스도 표시

## 3. jobs - 백그라운드 작업 확인

`jobs`는는 현재 쉘 세션에서 백그라운드(background)로 실행 중이거나 중지된 작업의 목록을 보여준다.

### 기본 사용법
```bash
jobs
```

### 출력 예시 및 설명
```Plaintext
[1]+  Running                 ./script.sh &
[2]-  Stopped                 vim textfile.txt
```
* [1], [2]: 작업 번호 (Job ID)
* +: 현재 작업 (fg나 bg 명령의 기본 대상)
* -: 이전 작업
* Running/Stopped: 상태

## 4. kill - 프로세스 종료 및 시그널 전송
`kill`은 프로세스에 특정 시그널(Signal)을 보낸다. 주로 프로세스를 종료할 때 사용하지만, 실제로는 다양한 신호를 보낼 수 있다

### 기본 문법
```bash
kill [옵션] [PID]
```

### 주요 시그널 옵션
| 옵션 | 시그널 이름 | 번호 | 설명 |
| :---: | :--- | :---: | :--- |
| (생략) | `SIGTERM` | **15** | **정상 종료 요청.** 프로세스가 정리 작업을 마치고 종료하도록 함 (권장) |
| `-9` | `SIGKILL` | **9** | **강제 종료.** 저장하지 않고 즉시 프로세스를 죽임 (주의 필요) |
| `-2` | `SIGINT` | **2** | **인터럽트.** 키보드 `Ctrl + C` 입력과 동일 |

### 사용 예시
```bash
# PID 1234 프로세스에게 정상 종료 요청 (가장 안전)
kill 1234

# PID 1234 프로세스 강제 종료 (응답이 없을 때 사용)
kill -9 1234
```
